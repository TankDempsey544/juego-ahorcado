# Juego del Ahorcado

**Descripcion del Juego:**
El juego del ahorcado es un juego de adivinanza de palabras donde los jugadores deben adivinar una palabra oculta seleccionando letras una por una. Si seleccionan una letra que no esta en la palabra, se dibuja una parte del cuerpo en la horca. El objetivo es adivinar la palabra antes de que se complete el dibujo.

**Reglas del Juego:**
1. Un jugador elige una palabra secreta y la escribe en formato de guiones bajos.
2. Los otros jugadores intentan adivinar la palabra mediante letras.
3. Si un jugador adivina una letra correcta, se revela en la posicion correspondiente. 
4. Si un jugador adivina una letra incorrecta, se suma una parte del cuerpo al ahorcado.
5. El juego termina cuando se adivina la palabra o se completa el dibujo del ahorcado.
